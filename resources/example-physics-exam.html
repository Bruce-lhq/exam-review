📂 §1.2 质点运动学 难度 ★

1. 一质点在 $x$ 轴上运动，加速度 $a = 4t$ (SI制)，$t=0$ 时 $x_0=0$，$v_0=2$ m/s，则 $t=3$ s 时质点的速度 $v =$ m/s。

答案：$v = 20$ m/s

解析：$v = v_0 + \int_0^3 a\,dt = 2 + \int_0^3 4t\,dt = 2 + 2t^2\big|_0^3 = 2 + 18 = 20$ m/s

📂 §2.6 非惯性系 难度 ★★

2. 地球自转角速度为 $\omega$，半径为 $R$，在赤道处物体的重力加速度 $g$ 与引力加速度 $g_0$ 的关系是 $g = g_0 -$ 。

答案：$g = g_0 - R\omega^2$

解析：赤道处惯性离心力最大，$F_c = mR\omega^2$，重力为引力减去离心力：$mg = mg_0 - mR\omega^2$。

📂 §3.1 动量定理 难度 ★

3. 质量为 $2$ kg 的物体受合力 $F = 6t$ (N) 作用，$t=0$ 时静止，则 $t=2$ s 时物体的动量大小为 kg·m/s。

答案：$p = 12$ kg·m/s

解析：$p = \int_0^2 F\,dt = \int_0^2 6t\,dt = 3t^2\big|_0^2 = 12$ kg·m/s

📂 §5.3 转动惯量 难度 ★★

4. 一均匀细杆长 $l = 1$ m，质量 $m = 2$ kg，绕过一端且垂直于杆的轴的转动惯量 $J =$ kg·m²。

答案：$J = \frac13 ml^2 = \frac13 \times 2 \times 1^2 = \frac23$ kg·m²

解析：均匀细杆绕过端点的轴：$J = \frac13 ml^2 = \frac13 \times 2 \times 1 = \frac23$ kg·m²。

📂 §4.7 机械能守恒 难度 ★★

5. 弹簧振子质量 $m=0.5$ kg，劲度系数 $k=8$ N/m，振幅 $A=0.1$ m，则系统的总机械能 $E =$ J。

答案：$E = \frac12 kA^2 = \frac12 \times 8 \times 0.01 = 0.04$ J

解析：弹簧振子机械能守恒，$E = \frac12 kA^2 = \frac12 \times 8 \times (0.1)^2 = 0.04$ J。

📂 §6.1 简谐振动 难度 ★

6. 一弹簧振子做简谐振动，振幅 $A=4$ cm，周期 $T=2$ s，$t=0$ 时质点位于 $x=2$ cm 处且向 $x$ 正方向运动，则初相 $\phi =$ 。

答案：$\phi = -\frac{\pi}{3}$

解析：$x = A\cos\phi$，$2 = 4\cos\phi$，$\cos\phi = 0.5$，$\phi = \pm\frac\pi3$。$v>0$ 故 $\phi = -\frac\pi3$。

📂 §7.2 简谐波 难度 ★

解析：$\lambda = uT = 4 \times 0.5 = 2$ m。

📂 §8.7 相对论质量 难度 ★★

8. 粒子以 $v=0.6c$ 运动时，其相对论质量是静质量的 倍。

答案：$\gamma = \frac{1}{\sqrt{1-0.36}} = \frac{1}{0.8} = 1.25$

解析：$\gamma = \frac{1}{\sqrt{1-(0.6)^2}} = \frac{1}{\sqrt{0.64}} = \frac{1}{0.8} = 1.25$，$m = \gamma m_0 = 1.25m_0$。

📂 §4.4 保守力 难度 ★

答案：无关

解析：保守力的特征：做功与路径无关，只取决于始末位置。$\oint \boldsymbol{F}_{\text{保}}\cdot d\boldsymbol{r} = 0$。

📂 §5.6 角动量守恒 难度 ★★

10. 舞蹈演员旋转时收回手臂，转动惯量由 $J_1$ 变为 $J_2$（$J_2 < J_1$），则角速度之比 $\omega_2/\omega_1 =$ 。

答案：$\frac{\omega_2}{\omega_1} = \frac{J_1}{J_2}$

📂 §4.2 动能定理 + §3.1 动量定理 难度 ★★★ 题型: 动力学综合

1.（10分）质量为 $m$ 的物体从高度 $h$ 处自由落下，与地面碰撞后弹起，弹起高度为 $h'$（$h' < h$）。求：

（1）地面对物体的冲量大小；（5分）

（2）若碰撞时间为 $\Delta t$，求地面对物体的平均冲力。（5分）

（1）$I = m(\sqrt{2gh} + \sqrt{2gh'})$

（2）$\bar{F} = \frac{m(\sqrt{2gh} + \sqrt{2gh'})}{\Delta t} + mg$

① 碰前速度 $v_1 = \sqrt{2gh}$（向下）
② 碰后速度 $v_2 = \sqrt{2gh'}$（向上）
③ 动量定理：$I - mg\Delta t = mv_2 - (-mv_1)$
④ 冲量 $I = m(v_1 + v_2) + mg\Delta t$
① $v_1 = \sqrt{2gh}$ ↓
② $v_2 = \sqrt{2gh'}$ ↑
③ $(N-mg)\Delta t = m(v_2+v_1)$
④ $\bar{N} = \frac{m(v_1+v_2)}{\Delta t} + mg$

⚠️ 陷阱：注意速度的方向性，碰前向下为负，碰后向上为正。

📂 §3.5 质心 + §6.1 简谐振动 难度 ★★★

2.（12分）两个质点质量分别为 $m_1=1$ kg、$m_2=3$ kg，开始时静止相距 $l=0.4$ m，在相互间的万有引力作用下运动（可忽略其他力）。已知引力常量 $G$。

（1）求系统的质心位置；（3分）

（2）求两质点相遇时的相对速度大小。（9分）
（提示：两体问题，利用约化质量）

（1）距 $m_1$ 距离：$x_C = \frac{3}{4}l = 0.3$ m

（2）$v_r = \sqrt{\frac{8G}{l}(m_1+m_2)} = \sqrt{\frac{32G}{l}}$（代入 $l=0.4$ m）

① 质心：$x_C = \frac{m_1 x_1 + m_2 x_2}{m_1+m_2}$
② 约化质量 $\mu = \frac{m_1 m_2}{m_1+m_2}$
③ 机械能守恒：$-\frac{G m_1 m_2}{l} = \frac12 \mu v_r^2 - \frac{G m_1 m_2}{0}$
① $x_C = \frac{1\cdot 0 + 3\cdot 0.4}{4} = 0.3$ m
② $\mu = \frac{1\times 3}{4} = 0.75$ kg
③ $v_r = \sqrt{\frac{2Gm_1 m_2}{\mu l}} = \sqrt{\frac{8G}{l}}$
📂 §5.2 定轴转动 + §2.5 牛顿定律应用 难度 ★★★

3.（10分）轻绳跨过一个质量为 $M=2$ kg、半径为 $R=0.1$ m 的均匀圆盘定滑轮（$J=\frac12 MR^2$），两端悬挂质量 $m_1=1$ kg 和 $m_2=3$ kg 的重物，绳与滑轮无相对滑动，轴承光滑。求：

（1）系统的加速度大小；（5分）

（2）绳中张力 $T_1$ 和 $T_2$。（5分）

（1）$a = \frac{(m_2-m_1)g}{m_1+m_2+M/2} = \frac{2\times9.8}{1+3+1} = 3.92$ m/s²

（2）$T_1 = m_1(g+a) = 13.72$ N，$T_2 = m_2(g-a) = 17.64$ N

对 $m_1$：$T_1 - m_1g = m_1a$；对 $m_2$：$m_2g - T_2 = m_2a$

对滑轮：$(T_2 - T_1)R = J\alpha = \frac12 MR^2 \cdot \frac{a}{R}$

解得：$a = \frac{(m_2-m_1)g}{m_1+m_2+M/2}$

📂 §7.9 多普勒效应 难度 ★★★

4.（10分）一列火车以 $u=30$ m/s 的速度驶近静止的观察者，火车鸣笛频率为 $\nu_0 = 500$ Hz，声速 $v=340$ m/s。求：

（1）观察者听到的笛声频率；（5分）

（2）火车驶过后观察者听到的频率变化了多少？（5分）

（1）$\nu' = \frac{v}{v-u}\nu_0 = \frac{340}{310}\times500 \approx 548.4$ Hz

（2）驶过后 $\nu'' = \frac{v}{v+u}\nu_0 = \frac{340}{370}\times500 \approx 459.5$ Hz，变化约 $88.9$ Hz

解析：多普勒效应公式 $\nu' = \frac{v\pm v_o}{v\mp v_s}\nu_0$。

驶近时观察者静止 $v_o=0$，声源移近取减号：$\nu' = \frac{v}{v-u}\nu_0$。

驶远时声源远离取加号：$\nu'' = \frac{v}{v+u}\nu_0$。

📂 §8.5 尺缩钟慢 难度 ★★★

5.（12分）一宇宙飞船以 $u=0.8c$ 的速度相对地面飞行。

（2）地面观察者测得飞船上的时钟走 $1$ 小时，飞船上的宇航员认为过了多长时间？（4分）

（1）$l = l_0\sqrt{1-u^2/c^2} = 100\times0.6 = 60$ m

（2）$\Delta t_0 = \frac{\Delta t}{\gamma} = \frac{1}{1.25} = 0.8$ 小时

（3）光速仍为 $c$（光速不变原理）

📂 §5.7 平面平行运动 + §3.8 角动量守恒 难度 ★★★★

6.（16分）一质量为 $m$、半径为 $R$ 的均匀圆盘（$J=\frac12 mR^2$）在水平面上以质心速度 $v_0$ 向右做纯滚动。

（1）求圆盘的角速度 $\omega_0$ 和总动能；（4分）

（2）若圆盘前进中与一高 $h=\frac12 R$ 的台阶发生完全非弹性碰撞，求碰后瞬间圆盘的角速度。（6分）

（3）要使圆盘能翻上台阶，$v_0$ 至少多大？（6分）

（1）$\omega_0 = \frac{v_0}{R}$，$E_k = \frac12 mv_0^2 + \frac12 J\omega_0^2 = \frac34 mv_0^2$

（2）碰后 $\omega = \omega_0 \cdot \frac{1}{1+\frac{2h}{R}}$（对台阶边缘角动量守恒）

（3）由机械能守恒：$\frac12 J\omega^2 + \frac12 mv_C^2 \ge mgh$ → 可解出 $v_{0\min}$

一、填空题（每空3分，共30分）

📂 §1.7 相对运动难度 ★★

1. 一人向东以 $v_1=4$ m/s 行走，感觉风从正北吹来；当速率为 $v_2=6$ m/s 向东时，感觉风从东北吹来，则风速大小为 m/s。

答案：$v = 2\sqrt{5} \approx 4.47$ m/s

设风速 $\boldsymbol{v} = (v_x, v_y)$。由题意：$v_x - 4 = 0$（正面风）→ $v_x = 4$；$v_y - 0 = 0$。第二次：$v_x - 6 = v_y$（东北风45°）→ $v_y = 4-6 = -2$。所以 $v = \sqrt{4^2+2^2}=2\sqrt5$ m/s，方向东南。

📂 §3.4 变质量难度 ★★★

2. 火箭初始质量 $M_0$，燃料喷出相对速度 $u$，燃料燃尽后火箭质量 $M_f$，不计重力，则火箭最终速度 $v_f =$ 。

答案：$v_f = u\ln\frac{M_0}{M_f}$

由动量守恒：$M dv = -u\,dM$，积分得 $v_f - v_i = u\ln\frac{M_i}{M_f}$。

📂 §4.12 伯努利方程难度 ★★

3. 理想流体在水平管中定常流动，截面积 $S$ 处的流速 $v$，压强 $p$，密度 $\rho$，则同一流管中截面积 $S/2$ 处的压强为 。

答案：$p' = p - \frac32 \rho v^2$

📂 §6.2 振动合成难度 ★★

📂 §2.5 + §3.2 动力学综合难度 ★★★

1.（10分）质量 $M=2$ kg 的楔块置于光滑水平面上，楔面光滑、倾角 $\theta=30^\circ$，质量 $m=1$ kg 的小滑块从楔块顶端静止滑下。求：

（1）楔块的加速度 $a_M$；（5分）

（2）小滑块相对楔块的加速度 $a'$。（5分）

$a_M = \frac{mg\cos\theta\sin\theta}{M+m\sin^2\theta} \approx 1.96$ m/s²

$a' = \frac{(M+m)g\sin\theta}{M+m\sin^2\theta} \approx 4.9$ m/s²

解析：利用非惯性系。在楔块参考系中，滑块受重力 $mg$、支持力 $N$ 和平移惯性力 $F_0 = -ma_M$。

滑块沿斜面方向：$mg\sin\theta + ma_M\cos\theta = ma'$

楔块水平方向：$N\sin\theta = Ma_M$

滑块法向：$N + ma_M\sin\theta = mg\cos\theta$

联立可解得。

📂 §3.7-3.9 角动量 + §4.7 机械能难度 ★★★★

2.（12分）质量为 $m$、速度为 $v_0$ 的小球与长为 $l$、质量为 $2m$ 的均匀细杆的一端发生完全非弹性碰撞（粘合），杆可绕光滑水平轴 $O$ 在竖直面内转动。

（1）求碰后瞬间杆的角速度；（6分）

（2）求杆能摆过的最大角度。（6分）

（1）$\omega = \frac{mv_0 l}{J}$，其中 $J = \frac13 (2m)l^2 + ml^2 = \frac53 ml^2$

$\omega = \frac{3v_0}{5l}$

（2）由机械能守恒：$\frac12 J\omega^2 = mgl(1-\cos\theta_{\max}) + 2mg\frac{l}{2}(1-\cos\theta_{\max})$

⚠️ 陷阱：完全非弹性碰撞过程中机械能不守恒，但角动量守恒（对 $O$ 点合外力矩为零）。碰后的摆动过程机械能守恒。

杆的转动惯量对 $O$ 端：$J_{\text{杆}} = \frac13 (2m)l^2$，小球视为质点 $J_{\text{球}} = ml^2$。

📂 §4.4 + §5.3 有心力 + 进动难度 ★★★★

3.（12分）地球绕太阳作椭圆轨道运动，太阳位于一个焦点上。设地球在近日点距太阳 $r_1$，速度为 $v_1$；在远日点距太阳 $r_2$。

（1）求远日点速度 $v_2$；（6分）

（2）求椭圆轨道的周期（用 $r_1$、$v_1$ 等表示）。（6分）

提示：开普勒第二定律（角动量守恒）和第三定律。

（1）角动量守恒：$mv_1 r_1 = mv_2 r_2$ → $v_2 = \frac{r_1}{r_2}v_1$

（2）$T = \frac{2\pi r_1 r_2}{v_1 r_2 - v_2 r_1}$ 或利用椭圆面积 $S = \pi ab$ 和掠面速度 $\frac{dS}{dt} = \frac{L}{2m}$

近日点和远日点处速度与位矢垂直，角动量 $L = mv_1 r_1 = mv_2 r_2$。

面积速度：$\frac{dS}{dt} = \frac{L}{2m}$，椭圆面积 $S = \pi a b = \pi\frac{r_1+r_2}{2}\sqrt{r_1 r_2}$，$T = S/(dS/dt)$。

📂 §6.5 受迫振动 + §7.7 驻波难度 ★★★★

4.（12分）一长为 $L$ 的两端固定的弦，其波速为 $u$。
