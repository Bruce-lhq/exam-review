# 使用示例 · 概率论与数理统计期末复习

本文件记录 exam-review skill 的**一次真实完整使用**：为一门 85+ 份资料的课程生成期末复习材料。所有对话节点均摘自真实运行记录，仅对教师姓名等做脱敏处理，措辞统一为"课堂笔记"。

---

## 场景

- **课程**：《概率论与数理统计》（课程号 10420803-4，2025-2026 春夏）
- **教材**：《概率论与数理统计教程》第三版（茆诗松）
- **阶段**：期末，覆盖一学期全部内容

## 输入：课程目录

```
概统/
├── PPT1.pdf ~ PPT14.pdf        # 14 份课件（按周）
├── 概统1.docx ~ 概统15.docx     # 15 份课堂笔记
├── 小结1.pdf ~ 小结14.pdf       # 14 份章节小结
├── 习题课/                      # 习题课资料 + 习题课笔记
├── 真题/                        # 历年真题
├── 作业/                        # 平时作业
└── 复习课.pdf、补充题.pdf、符号规范.pdf 等
共 85+ 份
```

---

## Step 1 · 触发

```
用户：/exam-review 整理全新的概统复习
```

skill 扫描目录，**统一用 markitdown 提取全部资料文本**，识别课程结构与考试信息，整理资料清单。

## Step 2 · 资料清单 + 知识大纲（等待确认）

skill 输出（节选）：

```
📋 资料清单（共 85+ 份文件）

课堂课件（PPT，14 份）
  PPT1    第 1 周：随机事件、概率定义与性质
  PPT2    第 2 周：条件概率、事件独立性
  PPT3    第 3 周：离散型随机变量
  ...
  PPT14   第 15 周：正态总体参数假设检验

课堂笔记（DOCX，15 份）
  概统1~15.docx   第 1-15 周课堂笔记

章节小结（PDF，14 份）
  小结1~14.pdf

📊 知识大纲（基于教学日历 + 真题分析）
  ...

🔍 请确认：
  1. 知识范围是否准确？需要排除或补充哪些章节？
  2. 是否有不需要参考的资料？
```

## Step 3 · 用户确认范围

```
用户：范围按照课堂范围来（4.1、5.2 等课上没提到的就排除）
```

skill 据此标注不考范围，避免在未覆盖内容上浪费篇幅：

- §4.1 大数定律详细理论（课堂未覆盖）
- §5.2 充分统计量、§5.5 次序统计量（未讲）
- §6.4 最小方差无偏估计、§6.5 贝叶斯估计、§6.7 分布参数估计（未讲）
- §7.3-7.5 非参数检验 / 拟合优度（未讲）

## Step 4 · 知识点标签审核（等待确认）

skill 从资料中自动提取两级标签：

```
🏷️ 知识点标签（两级层级）

随机事件与概率
  - 样本空间与事件运算 / 概率的公理化定义
  - 古典概型与几何概型 / 条件概率与乘法公式
  - 全概率公式与贝叶斯公式 / 事件独立性

一维随机变量
  - 离散型分布（二项/超几何/几何/负二项/泊松）
  - 连续型分布（均匀/指数/正态/伽马/贝塔）
  - 数学期望 / 方差与切比雪夫不等式

多维随机变量
  - 联合分布与边际分布 / 独立性
  - 协方差与相关系数 / 条件分布与条件期望

极限定理          → 大数定律 / 中心极限定理 / 特征函数
统计量与抽样分布   → 三大抽样分布（χ²/t/F）/ 正态总体抽样定理
参数估计          → 矩估计 / 极大似然估计 / 区间估计
假设检验          → 正态总体参数检验（Z/t/χ²/F 检验）

共 7 个一级标签、28 个二级标签。
请审核：是否有需要增减或合并的标签？
```

```
用户：OK
```

## Step 5 · 模拟卷题型确认 + 难度审核

skill 分析历年真题，展示题型分布并等待确认。确认后进入**难度审核**——先为每卷各生成一道代表题校准，循环至满意才生成完整卷：

```
用户：给个模拟样题呗
用户：和真题比怎么样？
用户：A 应该跟现在的 B 一样，B 全力模仿真题，C 在模仿真题的同时略微加大每题难度
```

这种"先出代表题、按反馈调难度、确认后再生成全卷"的循环，是 exam-review 模拟卷质量的关键。

## Step 6 · 生成

skill 依次生成 Part A → B → C → D → E，再生成模拟卷，最后输出汇总：

```
✅ 生成完成

📄 文件清单
  概统期末复习.html          交互式复习笔记（5 个 Part，81 张卡片）
  期末模拟真题.html          三套全真模拟卷（48 道题）
  .exam-review-manifest.json 项目清单（用于后续增量更新）

📊 复习笔记结构
  Part A 核心概念   7 章 28 节，含定义/公式/课堂强调/双栏对齐实例     28 卡
  Part B 题型归纳   12 类题型，含识别标志/通用解法/真题链接            12 卡
  Part C 易错点     概念性 8 个 + 方法性 8 个，双栏正误对比            16 卡
  Part D 真题详解   历年真题逐小问解析                                  16 卡
  Part E 习题大全   8 个专题，覆盖作业 + 习题课 + 补充题 50+ 道        8+ 卡

📝 模拟卷三卷
  A 卷 ★★   基础巩固   每题 1-2 章交叉，标准方法直接应用
  B 卷 ★★★  综合提升   全力匹配真题：三角形区域联合分布全链条、MLE + 矩估计 + 无偏性
  C 卷 ★★★★ 冲刺挑战   真题结构 + 每问深一度：Pareto 分布 MLE、Fisher 信息量、势函数

🎮 交互功能
  全文搜索 + 高亮 / 标签筛选(OR·AND 可切换) / 导航栈跨 Part 跳转 + 面包屑回退 /
  暗色模式 / 倒计时器 / 自评系统 + 底部计分栏(localStorage 持久化) / 打印适配 / KaTeX 公式
```

产出片段实物（浏览器可直接打开）：[`../resources/example-fragment.html`](../resources/example-fragment.html)

## Step 7 · 增量更新（第二次使用）

期末前用户往目录里加了新资料：

```
用户：我新加入了几个文件，请进行更新
```

skill 对照 manifest 识别变更，展示影响与可选范围：

```
检测到以下变更：

📁 新增文件：
  第 15 讲复习.pdf    影响：Part A 复习课专题 + 模拟卷参考
  习题课笔记/（6 个） 影响：Part E 习题解答细节 + Part A 课堂强调块

请选择更新范围：
  1. 全部更新（推荐）
  2. 仅更新 Part A + Part D（知识模块 + 真题）
  3. 仅更新 Part E（习题大全）
  4. 自定义
```

```
用户：1
```

skill 在新增内容处标注 🆕，精准更新对应 Part 与 manifest，**不必从头生成**。

## manifest 状态文件

每次生成后，课程目录下会写入 `.exam-review-manifest.json`，记录已处理文件、知识标签与 skill 版本，是增量更新与版本追溯的依据：

```json
{
  "course_name": "概率论与数理统计",
  "semester": "2025-2026春夏",
  "skill_version": "v1.0.0",
  "knowledge_tags": ["样本空间与事件运算", "古典概型与几何概型", "..."],
  "files_processed": {
    "PPT1.pdf": { "hash": "...", "last_modified": "2026-03-05" },
    "概统1.docx": { "hash": "...", "last_modified": "2026-03-03" }
  },
  "exam_structure": {
    "选择题": {"count": 5, "points_per": 3},
    "计算题": {"count": 4, "points_per": 10}
  }
}
```

## 小结

本次运行：**85+ 份散落资料 → 两份可交互的复习 HTML（81 张卡片 + 48 道题）**，全程 7 步、每步等待用户确认，最终支持增量更新。原本需要手工通读一整周的整理工作，被压缩为几次对话。

这个案例完整覆盖了 exam-review 的全部能力：多格式统一读取、逐项确认的对话流程、双栏对齐的复习笔记、难度可调的模拟卷、基于 manifest 的增量更新。
