# 数学型模板（math）

`exam-review` 的数学型模板，适用于高等数学、线性代数、概率统计、离散数学等以「定义 → 定理 → 公式 → 题型」为主干的理工课程。**也是默认回退模板**（§1.0 学科识别拿不准时用本模板）。

> 本文件是数学模板的**特有规格**：Part 集合、各 Part 字段、数学题型示例。
> 通用件——页面结构、交互机制（双栏对齐、导航栈、课堂强调、折叠、搜索、标签、暗色、打印）、KaTeX、样式基调、模拟卷三卷——见 `SKILL.md` §Phase 2。
> 完整范例见 `resources/example-math-review.html`、`resources/example-math-exam.html`。

## Part 集合：A–E

| Part | 内容 |
|---|---|
| A | 核心概念与定理 |
| B | 题型与解题方法归纳 |
| C | 高频考点 & 易错点 |
| D | 真题 / 例题详解 |
| E | 习题大全（可选） |

## Part A：核心概念与定理

每节一张**模块卡片**，核心内容字段 = **定义 / 定理 / 公式**（LaTeX）：

```
┌─ §3.1 偏导数 ───────────────────────────────────────┐
│ 考频: ████ 高 | 难度: 综合 | 来源 [展开 ▼]           │
│   └ 展开后列出具体文件+章节                           │
│                                                      │
│ ▸ 定义/定理（LaTeX 公式）                              │
│                                                      │
│   📌 课堂强调（点击展开原文）                      │
│   ⚠️ 易错陷阱 → 内联链接到 Part C                      │
│   🎯 高频考点 → 内联链接到 Part B/D                    │
│                                                      │
│   【速例】一步验证，简单直接                            │
│   📝 进阶训练见 → [Part B 某题型] [Part D 某真题]       │
│                                                      │
│   【实例解析】[📝 展开做题]（默认折叠，鼓励先做）        │
│   双栏对齐：左栏=通用解法流程（用变量符号）              │
│             右栏=具体例题步骤（带具体函数和数值）         │
│   每步横向对齐。含正误对比，易错写在 ❌ 行内。           │
│   优先用真题/习题课/作业原题或部分小问，标注出处。       │
│   无合适原题时可构造类似难度题目。                      │
└──────────────────────────────────────────────────────┘
```

**课堂强调的交互**：
```
📌 课堂强调（点击展开原文 ▼）
┌─ 课堂笔记原文（已纠错通顺）──────────────────┐
│ "偏导数存在但不连续的例子，期末考试一定考。    │
│  去年也考了，前年也考了。你要是搞不清楚        │
│  偏导存在和连续的关系，这5分就白丢了。"        │
│                                              │
│ 📍 来源：第3周课堂笔记.md 第45-48行           │
└──────────────────────────────────────────────┘
```
- 从课堂笔记提取课堂强调语句 → 标注为 `📌 课堂强调`
- **自动纠错**：对文本中的识别错误进行语义纠错（数学术语修正、同音字替换），改通顺后展示
- 末尾注明来源文件和位置
- 默认折叠，点击展开

## Part B：题型与解题方法归纳

按题型跨章节组织，每种题型一张卡片：

```
┌─ B.4 隐函数/参数方程求导 ──────────────────────────────┐
│ 关联知识：§3.1 偏导数 · §3.5 隐函数定理（inline链接）    │
│ 考频: █████ 极高 | 出现：2021-2024 每年至少1道大题       │
│                                        ← 返回 [来源]    │
│                                                         │
│ 题型描述 + 识别标志                                      │
│                                                         │
│ 双栏对齐（通用解法 ↔ 具体例题，逐行对齐）                  │
│                                                         │
│ ⚠️ 易错 → 链接到 Part C                                  │
│ 📝 变体训练                                              │
│ 🧪 真题实战见 → 链接到 Part D                             │
└─────────────────────────────────────────────────────────┘
```

数学典型题型（从资料实际提取）：极限计算、求导 / 积分、中值定理证题、Taylor 展开、多元微分（偏导 / 全微分 / 隐函数）、重积分、级数收敛、方程求解等。

## Part D：真题 / 例题详解

按年份组织，每道真题一张卡片：

```
┌─ 真题第5题（2023年 第三大题 · 12分）──────────────────┐
│ 知识点：§3.5 隐函数定理 · §4.1 方向导数（inline链接）   │
│ 题型归属 → [§B.4]  陷阱预警 → [§C.2.5] [§C.1.3]       │
│                                        ← 返回 [来源]    │
│                                                       │
│ 【题目】（完整誊写，支持一题多问）                        │
│ (1) … (4分)                                           │
│ (2) … (3分)                                           │
│ (3) … (3分)                                           │
│                                                       │
│ ┌─ (1) [4分] ──────────────────────────────────┐     │
│ │ [▶ 展开答案]  [▶ 展开解析]                      │     │
│ │ 解析含双栏（通用思路 ↔ 具体推导）+ ⚠️陷阱 + 💡技巧 │     │
│ └──────────────────────────────────────────────┘     │
│ ┌─ (2) [3分] ──────────────────────────────────┐     │
│ │ ⚠️ 依赖：(2)依赖(1)的结果，若(1)算错则(2)全错     │     │
│ │ [▶ 展开答案]  [▶ 展开解析]                      │     │
│ └──────────────────────────────────────────────┘     │
│ ...                                                  │
│ 📝 同类题 → [真题第8题] [作业7第3题]                    │
└──────────────────────────────────────────────────────┘
```

**一题多问规则**：
- 每小问独立 `[展开答案]` `[展开解析]`
- 解析中明确标注小问间依赖关系（如"⚠️ (2)依赖(1)的结果"）
- 每小问标注分值

## Part E：习题大全（可选）

按 Part B 的题型分类，收录**全部**作业题、习题课题、真题题目。与 Part D（真题精选）不同——Part D 精选代表性真题深度讲解，Part E 全覆盖海量训练。

在 Phase 1 对话中询问用户是否需要 Part E：

```
是否需要生成 Part E「习题大全」？
（按题型分类收录全部作业/习题课/真题题目，每题含完整题目+折叠解答+双栏推导）
1. 是，生成完整习题大全
2. 否，仅 Part D 真题精选即可
```

**Part E 与 Part D 去重规则：**
- Part D 中的真题在 Part E 中仅保留题目 + 链接 `📎 深度讲解见 → [§D 真题第X题]`，不重复撰写解答
- Part E 中的作业/习题课题目正常含完整解答
- 双向链接确保无缝跳转
