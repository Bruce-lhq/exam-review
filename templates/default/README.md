# 默认模板（数学型）

`exam-review` 的默认模板即**数学型**，适用于高等数学、线性代数、概率统计、离散数学等以「定义 → 定理 → 公式 → 题型」为主干的理工课程。

为避免过早抽象，默认模板的规格全部写在主入口 [`SKILL.md`](../../SKILL.md) 中，**不单独物化为 config.json**。需要时直接修改 SKILL.md 的相关章节即可。

## 模板覆盖的产出

**HTML 1 · 交互式复习笔记**（`xxxx期末复习.html`）

| Part | 内容 |
|---|---|
| A | 核心概念与定理（每节一张模块卡：定义/公式/课堂强调/双栏对齐实例） |
| B | 题型与解题方法归纳（跨章节，双栏对齐通用解法 ↔ 具体例题） |
| C | 高频考点 & 易错点（概念性 / 方法性，❌↔✓ 正误对比） |
| D | 真题/例题详解（逐小问展开，标注依赖与分值） |
| E | 习题大全（可选，按题型收录全部作业/习题课/真题） |

**HTML 2 · 全真模拟卷**（`期末模拟真题.html`）

A 卷基础巩固 / B 卷综合提升 / C 卷冲刺挑战，三套难度递进。

## 样式基调

暖白米色底（#fefcf7）、深棕字（#2c1810）、红色强调（#c41e3a）；KaTeX 渲染公式；双栏对齐表；暗色模式；打印适配。完整规范见 SKILL.md「HTML 样式指南」。

## 扩展其他学科

物理、化学、电路等学科若需专属模板（如物理加量纲分析、化学加方程式配平），走 SKILL.md「3b 扩展学科模板」流程，在 `templates/<学科名>/` 下新建配置目录。
