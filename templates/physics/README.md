# 物理型模板（physics）

`exam-review` 的物理型模板，适用于大学物理（力学 / 热 / 电 / 光 / 近代物理）等以「模型 → 定律 → 公式 → 题型」为主干的课程。

> 本文件只记物理模板的**特有部分**（Part A–F 的 delta、Part C 模型图鉴、SVG 约定、专题分类规则）。
> **通用件**——页面结构、交互机制（双栏对齐、导航栈、课堂强调、折叠、搜索、暗色、打印）、KaTeX、样式基调、模拟卷三卷、Part 类型骨架——见 `SKILL.md` §Phase 2。模型卡 SVG + KaTeX 样例见 `resources/physics-models-svg-demo.html`。

## 与数学型模板（math）的核心差异

| 维度 | 数学（math） | 物理（physics） |
|---|---|---|
| Part 数 | A–E | **A–F** |
| 新增 Part | — | **C 经典模型图鉴** |
| 编号顺延 | C 易错 / D 真题 / E 习题 | **D 易错 / E 真题 / F 习题** |
| 物理图像 | 无 | **SVG**（几何 + 力矢量） |
| 知识卡核心字段 | 定义 / 定理 / 公式 | 定律 / 公式 + **适用条件** + **量纲** |

## Part A：知识卡核心字段 = 定律 / 公式 + 适用条件 + 量纲

知识卡机制（考频/来源、📌课堂强调、⚠️易错链接、🎯高频考点、速例、双栏实例解析）见 SKILL.md。**物理的核心内容字段**为：

- ① **定律 / 公式**（KaTeX）+ 物理意义（一句话）
- ② **适用条件** ← 物理命根子（定律层级：动量守恒需合外力 = 0；理想气体方程需高温低压）
- ③ **量纲 / 单位**（如 $[p]=\mathrm{kg\cdot m/s}$）

> **双栏对齐不放 Part A**——Part A 是"认识定律"，Part B 才是"解题"。
> **适用条件（Part A，定律层）vs 模型假设（Part C，场景层）**：前者是普遍规律的成立前提，后者是单个模型的取近似。两层不同，不重复。

## Part B：题型归纳（沿用通用双栏，换物理题型）

题型归纳卡 + 双栏对齐机制见 SKILL.md。物理题型：受力分析 / 动力学题、守恒律题（动量 / 能量 / 角动量）、刚体转动题、振动方程题、相对论运动学、估算法等。每题型卡加反链 `关联模型 → [§C.x]`。

## Part C：经典模型图鉴（🆕 物理独有）

物理学习的核心是**模型库**。每个经典模型一张卡，**8 字段**：

| 字段 | 内容 |
|---|---|
| ① 模型名 + 分类 chip | 圆锥摆 `[动力学模型 · 圆周运动]` |
| ② 物理图像（SVG）+ 公式 caption（KaTeX） | 示意图 + $T\cos\theta=mg,\ T\sin\theta=mv^2/r$ |
| ③ 模型假设 / 适用条件 | 质点 · 绳不可伸长 · 无阻尼 · 匀速圆周 |
| ④ 核心方程 / 特征量（KaTeX） | $T=2\pi\sqrt{L\cos\theta/g}$ |
| ⑤ 通解流程 | ①受力分解 ②竖直/水平列方程 ③几何关系 $r=L\sin\theta$ ④求解 |
| ⑥ 易混模型对比 | 单摆（重力恢复）vs 圆锥摆（向心力）vs … |
| ⑦ 变体与进阶 | → 傅科摆 → 锥体上滚（承接专题难题） |
| ⑧ 关联（live § 链接） | → [§A.3] → [§B.4] → [§E 真题] |

**按专题分类**：运动学 / 动力学 / 守恒（碰撞 · 天体 · 弹簧）/ 刚体 / 振动波 / 相对论 / 非惯性系模型。

**SVG 约定**（样例 `resources/physics-models-svg-demo.html`）：

- SVG 只画**几何 + 力矢量方向**，标签用**单符号**（T / N / f / θ / L / mg / r）
- **多符号表达式交给 KaTeX**，放图下 caption（`mg sinθ` 这类**不进 SVG**）
- 力矢量红 `#c41e3a`；构造线虚线灰 `#b5a48f`；变量斜体衬线
- **KaTeX 不嵌进 SVG**（避免 `foreignObject` 在 PDF 导出时脆弱）

**不做"典型例题"详解**——例题归 Part B / Part E，模型卡只放 ⑧ 关联指针。

## Part D / E / F：沿用通用 Part

- **Part D 易错点**（通用 ❌ vs ✓，见 SKILL.md）：物理经典易错如有限角位移非矢量、功与作用点、瞬心加速度 ≠ 0。
- **Part E 真题详解**（通用一题多问，见 SKILL.md）：物理大题形态天然契合；解析可选配 SVG 受力图。
- **Part F 习题大全**（可选，通用，见 SKILL.md）。

## 专题资料分类规则

对"各类问题 / 专题难题"类资料，按性质三分（内容并入目标卡对应字段，不稀释）：

- **模型拓展型**（有装置 / 情境）→ **Part C**（独立模型卡，或父模型 ⑦ 变体）
- **概念 / 原理深化型**（讲清概念定律）→ **Part A**（相关卡的注解）
- **细节陷阱型**（常见错误 / 反直觉点）→ **Part D**（独立易错卡）
