# Template Studio 标准模板包骨架

本文件是 Template Studio 生成新课程模板时使用的**输出规范与缺省回填依据**，不是逐项询问用户的表单。生成模板时应优先参考用户想法、课程资料目录、真题/作业和既有默认模板；只有信息无法推断且会影响模板结构时，才向用户提问。

当两个设计方案效果接近、证据不足或收益不明显时，优先选择更接近默认模板和通用 HTML 结构的方案。

---

## 模板元信息

| 字段 | 填写规则 |
|---|---|
| 模板名称 | 必填。使用清晰中文名，如“案例论述型课程模板”。 |
| slug | 必填。小写英文、数字和连字符，如 `case-discussion`。可由课程名自动生成。 |
| 复习形态 | 必填。可多选：计算推导型 / 概念记忆型 / 案例论述型 / 实验实践型 / 混合型。 |
| 模板基底 | 必填。`math` / `physics` / `common` / `from-scratch`。效果接近时优先选更接近已验证模板的基底。 |
| 适用课程 | 必填。从课程资料和用户目标推断。 |
| 不适用课程 | 可推断。无法判断时写保守边界。 |

## 资料需求

说明该模板最适合读取哪些资料。优先从当前课程目录反推，不要求用户补齐所有类型。

| 资料类型 | 是否建议 | 用途 |
|---|---|---|
| 课件 / 教材提纲 | 建议 | 提取章节结构、核心概念、理论框架。 |
| 课堂笔记 | 建议 | 提取课堂强调、老师偏好、常见提醒。 |
| 作业 / 习题课 | 建议 | 推断训练方式、题型、易错点。 |
| 真题 / 样卷 | 有则优先 | 推断考法、分值、第二份 HTML 类型。 |
| 实验 / 案例 / 材料 | 按课程需要 | 构造实验复盘、案例分析或材料论述卡。 |

## Part 结构

Part 数量默认控制在 4-6 个。可并入已有 Part 的内容不新增 Part；只有资料和用户目标都支持时才新增。

| Part | 名称 | 作用 | 来源线索 | 是否必需 |
|---|---|---|---|---|
| A | 核心概念 / 基础框架 | 放最稳定、最常用的复习主干。 | 课件目录、教材提纲、课堂笔记。 | 是 |
| B | 题型 / 方法 / 框架归纳 | 放跨章节的解题、论述或分析方法。 | 作业、真题、讨论题。 | 建议 |
| C | 易错点 / 对比辨析 | 放容易混淆或容易扣分的内容。 | 课堂强调、错题、真题解析。 | 建议 |
| D | 真题 / 训练 / 案例详解 | 放完整题目、材料或案例训练。 | 真题、作业、案例材料。 | 建议 |
| E | 习题大全 / 专题训练 / 复盘清单 | 放全覆盖训练或替代训练形式。 | 作业、习题课、实验要求。 | 可选 |

生成新模板时可以改名、合并或替换 Part，但必须说明理由。

## 卡片字段

字段宁可少而稳定。资料中不稳定出现的字段放入“补充说明”或“扩展字段”，不要设为必填。

### 知识 / 概念卡

- 名称
- 所属标签
- 核心定义 / 结论 / 框架
- 适用条件 / 使用场景
- 易混点
- 来源
- 关联训练

### 方法 / 题型 / 论述卡

- 题型或任务描述
- 识别标志
- 通用步骤
- 典型例题 / 案例
- 常见错误
- 变体训练
- 来源

### 案例 / 材料卡

- 案例背景
- 可调用理论 / 方法
- 分析角度
- 可引用材料
- 风险点 / 易误读处
- 来源

### 实验 / 实践卡

- 实验目标 / 任务目标
- 核心原理
- 操作流程
- 数据处理 / 误差分析
- 报告要求
- 常见问题
- 来源

## 标签体系

默认采用两级标签：

- 一级标签：章节、主题、理论模块或实验模块。
- 二级标签：具体知识点、方法、题型、案例类型或实验步骤。

筛选逻辑沿用通用 HTML：默认 OR，多选可切换 AND。

## 题型 / 考法归纳规则

优先级：

1. 真题 / 样卷。
2. 作业 / 习题课 / 讨论题。
3. 课件中的例题和课堂强调。
4. 用户对考试形式的明确说明。
5. 模板默认值。

如果真题和作业能推断考法，不重复询问用户；只在证据冲突或缺失时提供推荐项让用户确认。

## 输出 HTML 策略

默认输出两份 HTML：

1. `课程名期末复习.html`：复习笔记、知识结构、题型/方法、易错点、训练链接。
2. 第二份训练 HTML：默认沿用 `期末模拟真题.html`。若课程形态不适合传统模拟卷，可改名为 `期末训练题.html`、`案例论述训练.html`、`实验复盘清单.html` 等。

只有用户明确需要，或资料强烈支持，才增加第三份 HTML。

## Auto Mode 默认行为

沿用主 skill 的 Auto Mode 规则：

- 保留用户已确认的模板设计。
- 对未确认字段使用资料推断和本骨架默认值。
- 当两个方案效果接近时，选择更接近默认模板和通用结构的方案。
- 将自动假设写入 HTML 顶部摘要和 `.exam-review-manifest.json`。

## 增量更新影响

生成模板包时应说明常见资料变更会影响哪些 Part：

| 资料变化 | 默认影响 |
|---|---|
| 新增课件 / 教材章节 | Part A、标签体系、相关 Part 引用。 |
| 新增作业 / 习题课 | Part B、Part D/E、易错点。 |
| 新增真题 / 样卷 | 考法归纳、第二份 HTML、真题详解。 |
| 新增课堂笔记 | 课堂强调、易错点、标签命名。 |
| 新增案例 / 实验材料 | 案例卡、实验卡、训练 HTML。 |

## 分享说明

分享模板包时必须说明：

- 适合哪些课程。
- 不适合哪些课程。
- 主要依据哪些资料和用户反馈生成。
- 其他同学复用时，应先用自己的课程资料重新校准。
- 模板可复制给同学、提交到 skill 仓库，或作为未来模板广场候选。

## 贡献者 / 来源说明

默认格式：

```text
模板来源：由 Template Studio 基于用户提供的课程资料与反馈共创生成。
贡献者：<用户可填写姓名或匿名>
生成日期：<YYYY-MM-DD>
适用范围：<同一课程/同类课程/同一老师课程>
```
