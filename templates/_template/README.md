# Template Studio 最小可用模板规范

本文件是 Template Studio 生成新课程模板时使用的**最小输出骨架与回退校验清单**，不是逐项询问用户的表单。数学型和物理型模板已经证明：一个模板不需要填满档案字段，也可以完整工作；关键是写清楚**适用范围、组织主线、Part 结构、卡片字段差异、输出策略差异，以及与通用件的关系**。

生成模板时应优先参考用户想法、课程资料目录、真题/作业和既有默认模板。当两个设计方案效果接近、证据不足或收益不明显时，优先选择更接近默认模板和通用 HTML 结构的方案。

---

## 最小必需结构

新模板 README 至少需要写清以下内容。

### 1. 模板定位

用一两句话说明：

- 这个模板适合哪些课程。
- 这类课程的复习组织主线是什么。

示例：

```text
本模板适用于以“案例 → 理论 → 论述题”为主干的通识/社科课程。
```

### 2. 与通用件的关系

说明哪些部分沿用 `SKILL.md` 的通用机制，哪些是本模板特有。

通常沿用：

- 页面结构。
- 搜索、标签、折叠、导航栈。
- 暗色模式、打印、KaTeX。
- 资料读取、Auto Mode、manifest、增量更新总规则。

模板只需要写本课程类型的差异，例如：

- Part 是否新增或顺延。
- 知识卡核心字段是否变化。
- 是否需要模型图、案例卡、实验卡、论述题训练卡。
- 第二份 HTML 是否仍是模拟卷，还是替换为训练集/复盘清单。

### 3. Part 结构

列出 Part 集合和每个 Part 的作用。Part 数量默认控制在 4-6 个；能并入已有 Part 的内容不新增 Part。

```markdown
| Part | 内容 |
|---|---|
| A | 核心概念与框架 |
| B | 方法 / 题型 / 论述结构 |
| C | 易错点 / 对比辨析 |
| D | 真题 / 案例 / 训练详解 |
| E | 习题大全 / 专题训练（可选） |
```

### 4. 卡片字段

只写本模板相对通用件的关键字段差异。字段宁可少而稳定；资料中不稳定出现的字段放入补充说明，不设为必填。

示例：

```markdown
## Part A：知识卡核心字段

- 定义 / 观点
- 适用语境
- 易混概念
- 可引用案例
```

### 5. 输出 HTML 策略

默认输出两份 HTML：

1. `课程名期末复习.html`
2. 第二份训练 HTML

如果沿用默认模拟卷，只需写：

```text
模拟真题 HTML 沿用 SKILL.md 通用规则。
```

如果第二份 HTML 要替换，才说明替换原因和结构：

```text
本模板不生成传统限时模拟卷，第二份 HTML 改为“材料分析与论述训练.html”。
```

### 6. 特有规则

写明该模板真正区别于默认模板的规则。没有特有规则时可以省略。

示例：

- 物理模板的 SVG 图像约定。
- 案例论述模板的案例嵌入方式。
- 实验模板的实验流程和误差分析字段。
- 法学模板的法条 / 案例 / 争点结构。

## 可选补充

以下内容有用，但不是模板能工作的必要条件。Template Studio 可以从资料自动推断、用默认值回填，或在需要分享时补充。

- 模板名称。
- slug。
- 不适用课程。
- 资料需求。
- 标签体系。
- 题型 / 考法归纳优先级。
- 示例卡片。
- 分享说明。
- 贡献者 / 来源说明。
- 增量更新影响。

这些内容不应变成逐项提问。只有当缺失信息会改变 Part 结构、卡片字段或输出 HTML 时，才向用户确认。

## 全局默认

以下规则属于 `SKILL.md` 的全局机制，不要求每个模板 README 重复书写：

- Auto Mode 默认行为。
- 增量更新通用规则。
- manifest 版本追溯。
- 搜索、标签、折叠、导航栈、打印、暗色模式。
- 证据优先级：真题 / 作业 / 课件 / 用户说明 / 模板默认值。
- 保守偏默认：效果接近时沿用已验证模板和通用结构。
